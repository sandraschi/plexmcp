# Documentation images

| File | Represents | Notes |
|------|----------------|------|
| `overview.svg` | Dashboard / server overview | Stylized wireframe; replace with a real screenshot for marketing if needed |
| `search.svg` | Keyword or semantic search | Same |
| `settings.svg` | Webapp settings (Plex, LLM, RAG) | Same |

These **SVG** previews keep the repo lightweight and readable in GitHub. For release posts or the wiki, capture PNGs from a running `webapp` and drop them here with the same basenames (update links in [WEBAPP.md](../WEBAPP.md) to `.png` if you switch format).
